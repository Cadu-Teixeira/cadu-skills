# frontend-design

**Grupo:** Design e interface  
**Origem:** Anthropic

## Para que serve
Orienta interfaces mais consistentes e menos genéricas: hierarquia, tipografia, espaçamento, estados.

## Onde eu utilizo
Nas telas e páginas dos meus projetos e deste portfólio.

## Como instalar
```bash
npx skills add anthropics/skills --skill frontend-design
```

## Atenção
Não substitui um designer; teste com pessoas.

## Antes de instalar
Leia o `SKILL.md` e os scripts da skill. Teste em um projeto sem dados sensíveis.
