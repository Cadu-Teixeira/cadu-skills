# content-strategy

**Grupo:** Conteúdo  
**Origem:** Comunidade (skills.sh)

## Para que serve
Organiza temas, formatos, canais e reaproveitamento de conteúdo.

## Onde eu utilizo
Planejar vídeos, posts e newsletter a partir de um tema.

## Como instalar
```bash
npx skills find content-strategy
```
O repositório de origem pode variar. Abra a página da skill em https://skills.sh, confira quem mantém e copie o comando atual.

## Antes de instalar
Leia o `SKILL.md` e os scripts da skill. Teste em um projeto sem dados sensíveis.
