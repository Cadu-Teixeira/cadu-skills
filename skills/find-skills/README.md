# find-skills

**Grupo:** Criar e descobrir  
**Origem:** Comunidade (skills.sh)

## Para que serve
Encontra skills que já existem para uma tarefa.

## Onde eu utilizo
No início de um projeto, antes de criar algo do zero.

## Como instalar
```bash
npx skills add vercel-labs/skills --skill find-skills
```

## Antes de instalar
Leia o `SKILL.md` e os scripts da skill. Teste em um projeto sem dados sensíveis.

Esta ficha é um guia. O conteúdo da skill pertence ao autor original e segue a licença dele.
