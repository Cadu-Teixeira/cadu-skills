# skill-creator

**Grupo:** Criar e descobrir  
**Origem:** Anthropic

## Para que serve
Cria, melhora e testa skills próprias a partir de uma rotina sua.

## Onde eu utilizo
Transformo processos que repito (publicar conteúdo, montar propostas) em pacotes reutilizáveis.

## Como instalar
```bash
npx skills add anthropics/skills --skill skill-creator
```

## Antes de instalar
Leia o `SKILL.md` e os scripts da skill. Teste em um projeto sem dados sensíveis.

Esta ficha é um guia. O conteúdo da skill pertence ao autor original e segue a licença dele.
