# web-design-guidelines

**Grupo:** Design e interface  
**Origem:** Comunidade (skills.sh)

## Para que serve
Revisa interface e código: contraste, responsividade, estados e usabilidade.

## Onde eu utilizo
Depois da primeira versão de uma página, antes de mostrar ao cliente.

## Como instalar
```bash
npx skills find web-design-guidelines
```
O repositório de origem pode variar. Abra a página da skill em https://skills.sh, confira quem mantém e copie o comando atual.

## Antes de instalar
Leia o `SKILL.md` e os scripts da skill. Teste em um projeto sem dados sensíveis.
