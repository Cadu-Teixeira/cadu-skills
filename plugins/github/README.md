# github

## Para que serve
Servidor MCP oficial do GitHub: issues, pull requests, revisão e busca de repositórios.

## Onde eu utilizo
Gestão de repositórios.

## Como instalar
No Claude Code ou no Cowork:
```
/plugin
```
Abra a aba de descoberta, procure por `github` no marketplace e instale. Se tiver o comando exato do marketplace, use:
```
/plugin install github@<marketplace>
```

## Antes de instalar
Plugins podem executar comandos, hooks e conectar serviços externos. Confira o autor e as permissões.

O plugin é de terceiros. O conteúdo pertence ao autor original.
