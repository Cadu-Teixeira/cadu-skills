# Plugins que eu tenho instalados

Um plugin reúne skills, comandos, MCPs e agentes em um único pacote.

| Plugin | Para que serve | Onde utilizo |
|---|---|---|
| [`social-media-skills`](./social-media-skills/README.md) | Estratégia, roteiros, design, publicação e análise de redes sociais (106 skills). | Planejamento e produção do conteúdo das minhas redes. |
| [`headroom`](./headroom/README.md) | Trabalha com logs, documentos e JSON/CSV grandes sem encher o contexto: resume primeiro, lê só o necessário. | Arquivos grandes em projetos. |
| [`bulkpublish`](./bulkpublish/README.md) | Agenda posts, gerencia canais e acompanha métricas em 15 plataformas via MCP. | Agendamento de conteúdo. |
| [`cartographer`](./cartographer/README.md) | Mapeia, audita e refatora bases de código grandes, com revisores especialistas e backlog priorizado. | Auditoria dos meus projetos. |
| [`engineering`](./engineering/README.md) | Fluxos de engenharia: standup, revisão de código, decisões de arquitetura, incidentes e documentação. | Rotina de desenvolvimento. |
| [`design`](./design/README.md) | Crítica de design, design system, UX writing, acessibilidade, pesquisa e handoff. | Revisão das interfaces que construo. |
| [`claude-code-setup`](./claude-code-setup/README.md) | Analisa um projeto e recomenda automações para o Claude Code: hooks, skills, MCPs e subagentes. | Configurar novos projetos. |
| [`frontend-design`](./frontend-design/README.md) | Skill de design de frontend para UI/UX. | Interfaces dos sites e sistemas. |
| [`github`](./github/README.md) | Servidor MCP oficial do GitHub: issues, pull requests, revisão e busca de repositórios. | Gestão de repositórios. |
| [`21st`](./21st/README.md) | Encontra componentes de UI e temas e recupera o código. | Componentes para os sites. |
| [`postiz`](./postiz/README.md) | CLI de automação de redes sociais: agendar posts, mídia e métricas em 28+ plataformas. | Publicação e métricas. |
