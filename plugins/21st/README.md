# 21st

## Para que serve
Encontra componentes de UI e temas e recupera o código.

## Onde eu utilizo
Componentes para os sites.

## Como instalar
No Claude Code ou no Cowork:
```
/plugin
```
Abra a aba de descoberta, procure por `21st` no marketplace e instale. Se tiver o comando exato do marketplace, use:
```
/plugin install 21st@<marketplace>
```

## Antes de instalar
Plugins podem executar comandos, hooks e conectar serviços externos. Confira o autor e as permissões.

O plugin é de terceiros. O conteúdo pertence ao autor original.
