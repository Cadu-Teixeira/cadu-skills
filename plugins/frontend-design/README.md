# frontend-design

## Para que serve
Skill de design de frontend para UI/UX.

## Onde eu utilizo
Interfaces dos sites e sistemas.

## Como instalar
No Claude Code ou no Cowork:
```
/plugin
```
Abra a aba de descoberta, procure por `frontend-design` no marketplace e instale. Se tiver o comando exato do marketplace, use:
```
/plugin install frontend-design@<marketplace>
```

## Antes de instalar
Plugins podem executar comandos, hooks e conectar serviços externos. Confira o autor e as permissões.

O plugin é de terceiros. O conteúdo pertence ao autor original.
