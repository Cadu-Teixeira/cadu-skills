# bulkpublish

## Para que serve
Agenda posts, gerencia canais e acompanha métricas em 15 plataformas via MCP.

## Onde eu utilizo
Agendamento de conteúdo.

## Como instalar
No Claude Code ou no Cowork:
```
/plugin
```
Abra a aba de descoberta, procure por `bulkpublish` no marketplace e instale. Se tiver o comando exato do marketplace, use:
```
/plugin install bulkpublish@<marketplace>
```

## Antes de instalar
Plugins podem executar comandos, hooks e conectar serviços externos. Confira o autor e as permissões.

O plugin é de terceiros. O conteúdo pertence ao autor original.
