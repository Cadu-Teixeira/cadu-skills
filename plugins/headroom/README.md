# headroom

## Para que serve
Trabalha com logs, documentos e JSON/CSV grandes sem encher o contexto: resume primeiro, lê só o necessário.

## Onde eu utilizo
Arquivos grandes em projetos.

## Como instalar
No Claude Code ou no Cowork:
```
/plugin
```
Abra a aba de descoberta, procure por `headroom` no marketplace e instale. Se tiver o comando exato do marketplace, use:
```
/plugin install headroom@<marketplace>
```

## Antes de instalar
Plugins podem executar comandos, hooks e conectar serviços externos. Confira o autor e as permissões.

O plugin é de terceiros. O conteúdo pertence ao autor original.
