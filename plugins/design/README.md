# design

## Para que serve
Crítica de design, design system, UX writing, acessibilidade, pesquisa e handoff.

## Onde eu utilizo
Revisão das interfaces que construo.

## Como instalar
No Claude Code ou no Cowork:
```
/plugin
```
Abra a aba de descoberta, procure por `design` no marketplace e instale. Se tiver o comando exato do marketplace, use:
```
/plugin install design@<marketplace>
```

## Antes de instalar
Plugins podem executar comandos, hooks e conectar serviços externos. Confira o autor e as permissões.

O plugin é de terceiros. O conteúdo pertence ao autor original.
