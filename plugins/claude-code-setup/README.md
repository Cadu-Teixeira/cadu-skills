# claude-code-setup

## Para que serve
Analisa um projeto e recomenda automações para o Claude Code: hooks, skills, MCPs e subagentes.

## Onde eu utilizo
Configurar novos projetos.

## Como instalar
No Claude Code ou no Cowork:
```
/plugin
```
Abra a aba de descoberta, procure por `claude-code-setup` no marketplace e instale. Se tiver o comando exato do marketplace, use:
```
/plugin install claude-code-setup@<marketplace>
```

## Antes de instalar
Plugins podem executar comandos, hooks e conectar serviços externos. Confira o autor e as permissões.

O plugin é de terceiros. O conteúdo pertence ao autor original.
