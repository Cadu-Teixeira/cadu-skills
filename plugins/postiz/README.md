# postiz

## Para que serve
CLI de automação de redes sociais: agendar posts, mídia e métricas em 28+ plataformas.

## Onde eu utilizo
Publicação e métricas.

## Como instalar
No Claude Code ou no Cowork:
```
/plugin
```
Abra a aba de descoberta, procure por `postiz` no marketplace e instale. Se tiver o comando exato do marketplace, use:
```
/plugin install postiz@<marketplace>
```

## Antes de instalar
Plugins podem executar comandos, hooks e conectar serviços externos. Confira o autor e as permissões.

O plugin é de terceiros. O conteúdo pertence ao autor original.
