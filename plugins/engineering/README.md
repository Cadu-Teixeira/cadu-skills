# engineering

## Para que serve
Fluxos de engenharia: standup, revisão de código, decisões de arquitetura, incidentes e documentação.

## Onde eu utilizo
Rotina de desenvolvimento.

## Como instalar
No Claude Code ou no Cowork:
```
/plugin
```
Abra a aba de descoberta, procure por `engineering` no marketplace e instale. Se tiver o comando exato do marketplace, use:
```
/plugin install engineering@<marketplace>
```

## Antes de instalar
Plugins podem executar comandos, hooks e conectar serviços externos. Confira o autor e as permissões.

O plugin é de terceiros. O conteúdo pertence ao autor original.
