# cartographer

## Para que serve
Mapeia, audita e refatora bases de código grandes, com revisores especialistas e backlog priorizado.

## Onde eu utilizo
Auditoria dos meus projetos.

## Como instalar
No Claude Code ou no Cowork:
```
/plugin
```
Abra a aba de descoberta, procure por `cartographer` no marketplace e instale. Se tiver o comando exato do marketplace, use:
```
/plugin install cartographer@<marketplace>
```

## Antes de instalar
Plugins podem executar comandos, hooks e conectar serviços externos. Confira o autor e as permissões.

O plugin é de terceiros. O conteúdo pertence ao autor original.
