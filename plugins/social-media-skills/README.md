# social-media-skills

## Para que serve
Estratégia, roteiros, design, publicação e análise de redes sociais (106 skills).

## Onde eu utilizo
Planejamento e produção do conteúdo das minhas redes.

## Como instalar
No Claude Code ou no Cowork:
```
/plugin
```
Abra a aba de descoberta, procure por `social-media-skills` no marketplace e instale. Se tiver o comando exato do marketplace, use:
```
/plugin install social-media-skills@<marketplace>
```

## Antes de instalar
Plugins podem executar comandos, hooks e conectar serviços externos. Confira o autor e as permissões.

O plugin é de terceiros. O conteúdo pertence ao autor original.
